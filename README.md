## Тема

АИС «Электронная библиотека».

Система позволяет вести реестр книг, жанров, пользователей и рецензий.  
Реализованы роли пользователей, загрузка обложек, Markdown-описание книг и модерация рецензий.

## Вариант 1

Функциональность модерации рецензий:

- у рецензий есть статусы: «На рассмотрении», «Одобрена», «Отклонена»;
- новая рецензия автоматически получает статус «На рассмотрении»;
- на странице книги отображаются только одобренные рецензии;
- пользователь видит раздел «Мои рецензии»;
- модератор видит раздел «Модерация рецензий»;
- модератор может одобрить или отклонить рецензию.

## Локальный запуск

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app\seed_db.py
set FLASK_APP=wsgi.py
flask run --port 5007
```

После запуска сайт доступен по адресу:

```text
http://127.0.0.1:5007
```

## Основные возможности

- просмотр списка книг;
- добавление книги администратором;
- редактирование книги администратором и модератором;
- удаление книги администратором;
- загрузка обложки книги;
- связь книг и жанров многие-ко-многим;
- написание рецензии пользователем;
- отображение только одобренных рецензий;
- модерация рецензий;
- разграничение прав доступа по ролям.
